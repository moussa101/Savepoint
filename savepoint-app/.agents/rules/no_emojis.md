# UI & Design Guidelines

## Absolutely No Emojis
- **NEVER** use emojis in the frontend, UI components, or empty states.
- If an icon is needed, use the pre-built SVG icons from `@/components/ui/Icons` or create a new SVG icon in that file.
- Emojis cheapen the premium aesthetic of the application and are strictly prohibited in the source code.

## Theme & Aesthetic
- Maintain a premium, dark-mode aesthetic with vibrant accents.
- Favor smooth transitions, micro-animations, and clean empty states using SVGs.
